# dsh-brand-color

DSH brand logo color picker. Adds **Settings → 品牌颜色** with preset swatches (including yellow/amber) and a custom color picker, then recolors only the brand logo mark and favicon. Works with DSH 0.2.0 and 0.2.2 (uses both the old `--dsh-brand-color` variable and the new `sidebar.brand.mark` slot CSS).

```sh
dsh plugin --profile web add dsh-brand-color
```

Independent plugin; it does not require dsh-mesh.
