# dsh-mesh-node

Mesh server for `dsh-mesh`. Exposes this machine to peer DSH nodes over MCP/HTTPS, with cross-device delegation and optional desktop-control tools (`pc_action` / `pc_app` / `pc_window` / `pc_browser`).

```sh
node src/cli.js serve
```

See the main repo for the full setup guide: https://github.com/LinYanZhi/dsh-mesh
