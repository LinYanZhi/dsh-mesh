# Contributing

Thanks for your interest! This project is in early development (v0.1.0).

- Open an issue to discuss before large changes.
- Keep PRs focused; one topic per PR.
- Run `node --check` on modified `.mjs` files before submitting.
- Never commit secrets, tokens, API keys, private IPs, or personal paths.
- English or Chinese are both welcome in issues/PRs and docs.
